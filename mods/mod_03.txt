26. Cancel Invoice Logic 
Cancel button should not delete the invoice. 
On Cancel: 
1. Confirmation popup. 
2. Ask cancellation confirmation/reason if required. 
3. Change status: 
Active → Cancelled 
4. Preserve invoice number. 
5. Preserve original invoice data. 
6. Move/show invoice under Cancelled tab. 
7. Cancelled invoice should no longer appear as Active. 
If GST Status = Filed: 
Cancel button disabled. 
27. Deleted Invoice Rule 
Deleted Invoice Cannot Be Undone: 
Once an invoice is deleted, the deletion is permanent and cannot be undone or restored. The deleted invoice will 
remain visible under the Deleted tab temporarily for record/reference purposes. 

===== PDF PAGE 52 =====
Automatic Permanent Removal: 
Deleted invoices should be automatically and permanently removed from the Deleted tab after the next calendar 
month ends. Once permanently removed, the deleted invoice record will no longer be available in the portal. 
Invoice Number Reuse: 
The invoice number of a deleted invoice can be reused for creating a new invoice, if required. 
If GST Status = Filed: 
Delete button disabled.

• 
Active 
• 
Cancelled 
•

And the same Deleted Document Rule applies: 
Once a document is deleted, it cannot be undone or restored. It will temporarily remain under the Deleted tab and 
will be automatically and permanently removed after the end of the next calendar month. The deleted document 
number can be reused for creating a new document. 
Important Developer Instruction 
Do not hard-code "Tax Invoice" into the common Billing components. 
The document type should be dynamic, for example: 
Document Type = Tax Invoice / Bill of Supply / Debit Note / Credit Note / Quotation / Delivery Challan 
The UI, labels, actions and messages should automatically change according to the selected documentType, while 
maintaining the same standard design and Behaviour across all modules. 
31. GST Filing Status Exception: 
Filed / Not Filed status will apply only to Tax Invoice, Bill of Supply, Debit Note and Credit Note. It will not apply to 
Quotation or Delivery Challan. Quotation and Delivery Challan will have their own independent status/behaviour 
and will remain completely separate from GST Filing Status.
